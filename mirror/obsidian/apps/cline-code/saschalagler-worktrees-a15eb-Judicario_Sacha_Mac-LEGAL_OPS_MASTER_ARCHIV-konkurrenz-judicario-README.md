# Judicario

Gerichtsfeste Rechtsrecherche & Schriftsätze für Claude Desktop.

**Tarif:** enterprise · **Credits:** 100000 · **Module:** Judicario Österreich, Judicario Deutschland, Judicario Schweiz, Judicario EU & Menschenrechte, Judicario IP · Copyright & Trademark (EU), Judicario Steuer · Abgabenrecht (AT)

## Connector
- `judicario-at` → Judicario Österreich
- `judicario-de` → Judicario Deutschland
- `judicario-ch` → Judicario Schweiz
- `judicario-eu` → Judicario EU & Menschenrechte
- `judicario-ip` → Judicario IP · Copyright & Trademark (EU)
- `judicario-steuer` → Judicario Steuer · Abgabenrecht (AT)

## Workflows (Tiles)
- `/recherche` — Rechtsprechung & Leitsätze recherchieren (AT/DE/CH/EU) — mit exakten Fundstellen
- `/norm` — Gesetzestext nachschlagen + einschlägige Judikatur
- `/gutachten` — Juristische Prüfung/Subsumtion zu einem Sachverhalt (Gutachtenstil)
- `/schriftsatz` — Gerichtsfesten Schriftsatz entwerfen (Klage/Berufung/Beschwerde/Antrag)
- `/fall-triage` — Eingehenden Fall einordnen: Rechtsgebiet, Dringlichkeit, nächste Schritte
- `/rechtsvergleich` — Grenzüberschreitender Rechtsvergleich AT/DE/CH/EU
- `/steuer` — Steuerrecht AT/DE: Urteile, Richtlinien, exakte Berechnung
- `/deckungscheck` — Versicherungsdeckung prüfen (AT/DE) — Konzepte, §§, AVB-Klauseln

Installation: 'Lokales Plugin hochladen' in Claude Desktop -> dieses Verzeichnis/ZIP waehlen.
